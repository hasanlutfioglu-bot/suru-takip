# Anime farm — 21.9.2

The new hand-painted scenery was generated using the built-in image_gen tool, then encoded as WebP at original resolution for delivery (514,014 bytes). Final project asset: `assets/farm/anime-countryside-v1.webp`. Original generation remains under the Codex generated_images directory.

Sheep artwork is original layered SVG with cel shading, expressive faces and wool highlights. Native SVG/CSS animation uses bounded walk / graze / return cycles with synchronized screen-space movement for recorded mothers and lambs. Finishing pen assignments and actual record identities are preserved. Night, pause, hidden/offscreen and reduced motion controls apply. Visual activity never creates livestock, feeding or financial records.

The background is included in the static deployment and offline asset cache. The local preview allows only the specific public farm asset directory. Tests verify the image loads, substantial movement, pen bounds, family synchronization, night/rest, pause/reduced motion and phone layouts. No live Supabase data is accessed.
