# Seven oldest lambs — 21.9.5

The default scene finishing rule follows the user's clarification: select the seven oldest currently active animals of type Kuzu using recorded birth date, regardless of sex. Dates must be valid and no later than today; missing dates are never guessed. Ties use stable record IDs. When a selected lamb leaves the active flock, the next oldest qualifies. With fewer than seven eligible animals, only known eligible animals are shown.

In this default mode only the chosen seven occupy the finishing area. The representative 24-figure budget reserves enough lamb figures for all seven, including when another lamb is highlighted by search or dialogue. Weaned lambs outside the seven do not return to a nursing mother position. A saved manual selection can switch the scene back to recorded-group/manual mode; the pen panel can restore oldest-seven mode.

This is a read-only presentation rule. No animal's group, status, parentage, weaning, weight or financial record is modified. Unit tests cover dated ranking, both sexes, exited/undated/future animals, stable order, replacement, large herds and preservation of data; existing scene/browser suites cover manual mode separately.
